# Changelog

## 1.0.0 (2026-11-13)

- WREL's Release Hour: a 1940s radio announcer reads a release report written by fixed rules from deploys, CI runs, incidents, rollbacks and SLO burn. Each day is fair skies, rough going, a freeze, an incident or the all clear; runs of the same kind of day become one segment.
- An urgent bulletin for every incident, with a station chime. An all clear when it resolves.
- A jazz-age WREL theme (generated with ElevenLabs) that opens, fades under the sign on and plays the show out.
- A real announcer two ways: one recorded read split at its pauses and checked against the script, or the ElevenLabs API with caching. Only the script text leaves the machine.
- Offline player with a cathedral radio, captions, a timeline that lights up the days being read, theme and chime buttons for a live read and The Record with the evidence behind every line.
- Static on the line instead of guessing when a source is missing or fails the data contract.
- Data contract checker, provenance, synthetic demo ("The Week Checkout Came Back"), tests and CI.
